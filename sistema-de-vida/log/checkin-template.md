# Check-in diário (copie uma linha por dia para `log/AAAA-MM.md`)

```
AAAA-MM-DD | modo: 🟢/🟡/🔴/✈️ | dormi: HH:MM→HH:MM (q:1-5) | corpo: treino/caminhada/nada (min) | comi: C/A/J = ok|meh|pulei | energia M/T/N: x/x/x | nota livre (≤1 linha)
```

Exemplo:
```
2026-11-09 | modo: 🟡 | dormi: 00:40→07:10 (q:3) | corpo: caminhada (20) | comi: ok/ok/meh | energia: 3/2/3 | reunião longa, cansei cedo
```

Regras: ≤30 segundos. Lacuna é dado válido. Não editar dias antigos para "melhorar" o registro.
