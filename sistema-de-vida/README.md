# Sistema de Vida

Um sistema pessoal para planejar e executar a vida com consistência, projetado a partir de **dados reais** (90 dias de agenda, Todoist e e-mail) e não de uma rotina ideal. Funciona nos dias bons e nos ruins.

## Em 2 minutos
1. Leia `02-sistema.md` (o modelo mental: Direção → Temporada → Semana → Dia + modos 🟢🟡🔴✈️).
2. Comece a **Semana 0**: `03-experimentos/00-semana-0-observar.md` (só registrar, sem mudar nada).
3. Use `/checkin` todo dia (2 min) e `/revisao-semanal` uma vez por semana.
